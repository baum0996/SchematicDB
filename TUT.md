# How to install Litematica

Litematica is a Minecraft client-side mod that lets you load and use `.litematic` schematics.

## 1. Install Fabric

Install the Fabric Loader for the Minecraft version you want to use.

## 2. Download Litematica

Download Litematica for your exact Minecraft version and Fabric version.

You can find it on Modrinth:
https://modrinth.com/mod/litematica

## 3. Download MaLiLib

Litematica requires MaLiLib.

Download the matching version:
https://modrinth.com/mod/malilib

Make sure both mods match your Minecraft version.

## 4. Put the mods into your mods folder

Open your Minecraft `mods` folder and put both `.jar` files inside:

```text
.minecraft/
└── mods/
    ├── litematica-....jar
    └── malilib-....jar
```

## 5. Start Minecraft

Start Minecraft using the Fabric profile.

If everything is installed correctly, press:

```text
M
```

to open the Litematica menu.

## Done

You can now download `.litematic` files from SchematicDB and load them with Litematica.
